# India Cost of Living Tracker 2025–2026

## Project Overview
An interactive Tableau dashboard analyzing essential commodity prices across India and comparing current retail prices with historical price changes.

## Objectives
- Identify commodities with the highest listed retail prices.
- Compare six-month and annual price changes.
- Highlight commodities with notable observed price increases.
- Present insights through clear, interactive visualizations.

## Tools & Technologies
- Tableau Public
- CSV
- Data Visualization
- Exploratory Data Analysis

## Dashboard Highlights
- Top 10 commodities by current listed price
- Top 10 commodities by annual price increase
- Comparison of six-month price changes
- Key findings based on the available data

## Data Source
Government of India, Department of Consumer Affairs:  
https://fcainfoweb.nic.in/Reports/DB/DBprices.aspx

## Important Data Notes
This project uses an all-India average retail commodity-price snapshot. Price changes are expressed as absolute rupee differences, not percentage inflation rates. The dataset does not provide a continuous daily or monthly time series, and the observed changes alone do not establish their causes.
